## 📌 Overview

Every time you train a neural network, one of the first decisions you make is choosing an optimiser.  
This project provides a **controlled comparison** of three popular optimisers:

- **SGD**
- **RMSProp**
- **Adam**

All experiments use:
- The same MLP architecture  
- The same CIFAR‑10 dataset  
- The same training setup  

The only variable is the **optimiser**.

This repository includes:
- The full Jupyter notebook  
- Training/validation curves  
- Final accuracy comparison  
- Additional SGD learning‑rate experiments  
- PDF tutorial report
